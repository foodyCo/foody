# Foody — Перечень функций

## Аутентификация

| Функция | Кто может | Эндпоинт |
|---------|-----------|----------|
| Получить JWT-токены (логин) | Все | `POST /api/v1/auth/token/` |
| Обновить access-токен | Все | `POST /api/v1/auth/token/refresh/` |

---

## Пользователи

| Функция | Кто может | Эндпоинт |
|---------|-----------|----------|
| Зарегистрироваться | Все | `POST /api/v1/users/register/` |
| Просмотреть свой профиль | Авторизованный | `GET /api/v1/users/me/` |
| Изменить свой профиль (bio, аватар, имя) | Авторизованный | `PATCH /api/v1/users/me/` |

---

## Посты — Чтение

| Функция | Кто может | Эндпоинт |
|---------|-----------|----------|
| Лента одобренных постов | Авторизованный | `GET /api/v1/posts/` |
| Поиск постов по блюду / ресторану | Авторизованный | `GET /api/v1/posts/?search=...` |
| Просмотреть пост | Авторизованный | `GET /api/v1/posts/{id}/` |
| Свои посты (все статусы) | Авторизованный | `GET /api/v1/posts/my/` |
| Сохранённые посты | Авторизованный | `GET /api/v1/posts/saved/` |
| Посты конкретного пользователя | Авторизованный | `GET /api/v1/posts/user_posts/?user_id=...` |

---

## Посты — Создание и редактирование

| Функция | Кто может | Эндпоинт | Примечание |
|---------|-----------|----------|-----------|
| Создать пост | Авторизованный | `POST /api/v1/posts/` | Статус `pending`, уходит на модерацию |
| Редактировать пост | Только автор | `PATCH /api/v1/posts/{id}/` | Статус сбрасывается в `pending`, пост уходит на повторную модерацию |
| Удалить пост | Автор или стаф | `DELETE /api/v1/posts/{id}/` | |

> **Что можно изменить при редактировании:** описание, цену, теги.
> **Что нельзя изменить:** блюдо, ресторан, рейтинг, фотографии.

---

## Лайки и сохранения

| Функция | Кто может | Эндпоинт | Примечание |
|---------|-----------|----------|-----------|
| Лайкнуть / снять лайк | Авторизованный | `POST /api/v1/posts/{id}/like/` | Повторный вызов снимает лайк |
| Сохранить / убрать из сохранённых | Авторизованный | `POST /api/v1/posts/{id}/save_post/` | Повторный вызов убирает из сохранённых |

---

## Комментарии

| Функция | Кто может | Эндпоинт | Примечание |
|---------|-----------|----------|-----------|
| Просмотреть комментарии к посту | Авторизованный | `GET /api/v1/posts/{id}/comments/` | Только у одобренных постов |
| Оставить комментарий | Авторизованный | `POST /api/v1/posts/{id}/comments/` | Только к одобренным постам |
| Удалить комментарий | Автор комментария или стаф | `DELETE /api/v1/posts/{id}/comments/{comment_id}/` | |

---

## Рестораны и блюда

| Функция | Кто может | Эндпоинт |
|---------|-----------|----------|
| Список ресторанов | Авторизованный | `GET /api/v1/restaurants/` |
| Поиск ресторанов по названию | Авторизованный | `GET /api/v1/restaurants/?search=...` |
| Список блюд | Авторизованный | `GET /api/v1/dishes/` |
| Блюда конкретного ресторана | Авторизованный | `GET /api/v1/dishes/?restaurant_id=...` |
| Поиск блюд по названию | Авторизованный | `GET /api/v1/dishes/?search=...` |

> Рестораны и блюда создаются автоматически при публикации поста. Ручного создания нет.

---

## Категории

| Функция | Кто может | Эндпоинт |
|---------|-----------|----------|
| Список категорий | Авторизованный | `GET /api/v1/categories/` |
| Поиск категорий | Авторизованный | `GET /api/v1/categories/?search=...` |
| Создать категорию | Стаф | `POST /api/v1/categories/` |
| Изменить категорию | Стаф | `PATCH /api/v1/categories/{id}/` |
| Удалить категорию | Стаф | `DELETE /api/v1/categories/{id}/` |

---

## Модерация (только стаф)

| Функция | Эндпоинт |
|---------|----------|
| Очередь постов на модерации | `GET /api/v1/moderation/` |
| Просмотреть пост из очереди | `GET /api/v1/moderation/{id}/` |
| Одобрить пост | `POST /api/v1/moderation/{id}/approve/` |
| Отклонить пост | `POST /api/v1/moderation/{id}/reject/` |

---

## Жизненный цикл поста

```
Создан / отредактирован
         │
         ▼
      pending  ◄──── редактирование автора (из любого статуса)
         │
    на модерации
         │
    ┌────┴────┐
    │         │
    ▼         ▼
approved   rejected
    │         │
публичен    виден только автору

Любой пост можно отредактировать → статус сбрасывается в pending
```
